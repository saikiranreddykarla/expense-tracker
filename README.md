# SpendWise Expense Tracker

A simple and responsive expense tracker built with React. It helps users add, edit, delete, search, and filter income and expense transactions.

## Live demo

[Open SpendWise Expense Tracker](https://saikiranreddykarla.github.io/expense-tracker/)

## Features

- View total balance, income, and expenses
- Add, edit, and delete transactions
- Search transactions by title
- Filter by transaction type, category, and month
- See recent transactions on the dashboard
- View spending by category
- Save transactions in browser local storage
- Responsive layout for mobile and desktop

## Built with

- React
- Vite
- Redux Toolkit
- React Router
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```
